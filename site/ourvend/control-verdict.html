Veredicto API / control

Mi lectura

  • No vi una API oficial pensada para integradores.
  • Sí vi una API interna de la propia web.
  • Sí vi una segunda interfaz H5/mobile.

Qué significa eso para Ballbox

  • Se puede investigar una capa propia arriba de la nube actual.
  • No conviene asumir estabilidad: vendor puede cambiar endpoints, params o checks.
  • Lo más realista es elegir 3 a 5 workflows clave y capturar tráfico real.

Workflows que más valen la pena investigar

  1. Abrir puerta
  2. Despacho remoto
  3. Editar precio/slot/producto
  4. Tomar screenshot o leer estado
  5. Upgrade/config remota
