Signal del manual oficial

Documento separado. Resume sólo señal útil extraída de las fotos del manual oficial. No reemplaza verdad comprobada ni partes fuente.

Qué aporta este doc

  • Captura señal operativa del manual TCN que sirve para investigar la máquina real.
  • No mezcla esto con la verdad comprobada de la máquina Ballbox.
  • Todo lo de acá debe leerse como: “el manual oficial TCN muestra/indica esto”.

Acceso local / menú

  • El manual muestra un login local de menú con password original 000000.
  • El menú mostrado incluye:
  • Slots management
  • Goods management
  • Password
  • Information settings
  • Payment setting
  • Program update
  • Serial port settings
  • Setup tool
  • Sales data
  • Function set

Information setting

  • El manual muestra campos de configuración para:
  • Server IP
  • Port number
  • Machine ID
  • Advertising setting
  • Pay tips
  • Price unit
  • Pay effective time
  • Ad download polling time
  • Standby picture time
  • Play image interval time
  • display the number of goods per page
  • number of slots digit
  • price decimal point

También muestra toggles/opciones como:

  • Standby advertisement display
  • Full screen
  • Ads on the bottom of the screen
  • Standby picture full screen display
  • Show type
  • Voice prompt
  • show single code
  • show shopping
  • check app foreground
  • Display touch prompt text
  • Use printer
  • Remote ad download

Remote ads / assets

  • El manual muestra estructura de carpetas bajo TcnFolder.
  • Carpetas observadas:
  • TcnFolder\ImageGoods
  • TcnFolder\VideoAndImageAd
  • TcnFolder\ImageScreen
  • TcnFolder\ImageBackground
  • TcnFolder\ImageHelp

La tabla del manual indica:

  • ImageGoods = imágenes de productos.
  • VideoAndImageAd = ads locales de video/imagen y también ads remotos descargados.
  • ImageScreen = standby full-screen video/picture ads.
  • ImageBackground = background picture.
  • ImageHelp = helping picture / ayuda.

Formatos soportados mostrados por el manual incluyen combinaciones de:

  • jpg, jpeg, png, gif
  • mp4, mkv, avi, wmv, flv

Import local por USB

  • El manual muestra flujo Update info with U disk.
  • Indica crear carpeta USB TcnImageGoods.
  • Indica crear archivo Excel tcn_product.xlsx.
  • La tabla ejemplo incluye columnas para:
  • slot number
  • product name
  • types of goods
  • product introduction
  • pictures of goods
  • product code
  • price
  • stock quantity
  • slot capacity

Backoffice / modificación remota

  • El manual describe Remote modification of slots information.
  • Indica que con la máquina online se usa cuenta WeChat subscription o browser para loguear al background system.
  • Desde ahí se puede elegir vending machine y slot, y definir precio, capacidad e imágenes.
  • También indica que settings del background system pueden sincronizarse a la máquina.

Serial / placas

  • El manual muestra dos boards de referencia:
  • TCN140613
  • TCN161114 (serial port board)
  • En serial port setup se muestran múltiples dispositivos/puertos, incluyendo variantes tipo ttymxc*, ttyGS* y ttyUSB*.
  • El manual marca baud rate sugerido por board:
  • 19200 para main board TCN140613
  • 38400 para main board TCN161114

  • Incluye contadores/montos para:

  • IC card
  • WeChat

Main board interfaces

  • El manual muestra interfaz física con referencias a:
  • WiFi antenna

Function set / menu settings

  • El manual muestra controles locales avanzados para:
  • temperature zones / heat / cool / close
  • drop sensor
  • coin fill
  • clear fault
  • query board faults
  • shipment inspection
  • port door control
  • diaphragm switch
  • parameter recovery factory value
  • set spring slot / belt slot
  • group and layer parameters
  • corriente, pasos, velocidad, sensor, bloqueo y otros parámetros mecánicos

Esto confirma que el menú local expone control profundo, pero no implica que deba tocarse sin cuidado.

Uso práctico recomendado

  • Usar este doc como mapa de dónde mirar en la máquina real.
  • Prioridad de inspección real: login local, Information setting, TcnFolder, VideoAndImageAd, Remote ad download, Server IP, Port number y Machine ID.
