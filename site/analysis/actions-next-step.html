Próximo paso: acciones

Siguiente fase recomendada: pasar de observación a ejecución sobre acciones reales de máquina.

Objetivo

Validar qué acciones se pueden disparar fuera de la UI principal y cuáles sirven para una integración útil de Ballbox.

Prioridad

  1. Screenshot remoto
  2. CRUD productos
  3. CRUD publicidad

Plan corto

  1. Elegir 1 máquina de prueba.
  2. Capturar tráfico de cada acción en PC y H5.
  3. Separar endpoints de lectura vs escritura.
  4. Repetir cada acción 2 o 3 veces para ver tokens, firmas y checks.
  5. Probar un cliente mínimo para la acción más valiosa.

Qué salida esperar

  • Lista de acciones realmente automatizables.
  • Riesgo por acción: bajo, medio, alto.
  • Primer endpoint usable para PoC.
  • Decisión: seguir con integración directa o frenar.
