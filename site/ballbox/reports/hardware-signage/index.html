Por qué 32GB

La Pi de prueba demostró que 16GB alcanza: ~7,2GB usados y layout 10GB root + 4,1GB persistente. Pero 32GB reduce riesgo de diferencias físicas entre tarjetas “16GB”, simplifica golden image y deja margen para cache, logs y updates. El costo extra SanDisk es solo ARS 60.000 por diez; con Lexar puede no existir.

Qué decide el lote

ONN PASS

  • Specs reales, API ≥26, ADB sin root.
  • V2 READY + rotación + ≥1GB libre.
  • dpm set-device-owner exitoso.
  • owner=yes locked=yes.
  • Home/Back/Recents no escapan.
  • 3 reboots + 3 cortes físicos.
  • 15 minutos offline + reconnect.
  • Burn-in 24h; 48h preferido.

ONN FAIL

Capturar error, factory reset, verificar pantalla inicial y devolver. Sin root, bootloader unlock ni hacks de paquetes de seguridad.
